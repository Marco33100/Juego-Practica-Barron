# Juego-Practica-Barron

Proyecto de juego 2D desarrollado en Unity. Incluye el nivel de recoleccion de frutas, un menu principal y ajustes de nombre, calidad, brillo, volumen y pantalla completa.

## Abrir el proyecto

1. Instala Unity **6000.3.23f1** desde Unity Hub.
2. Clona este repositorio y agrega su carpeta en Unity Hub.
3. Abre el proyecto y espera a que Unity importe los recursos.
4. Abre `Assets/Scenes/Menu.unity` y pulsa **Play**.

El boton Jugar abre `Nivel1`. La tecla Escape permite regresar al menu.

## Contenido

- `Assets/`: escenas, scripts, recursos y sus archivos `.meta`.
- `Packages/`: dependencias del proyecto.
- `ProjectSettings/`: configuracion de Unity.
- `LEEME-*.txt`: notas de las actividades implementadas.

Unity regenera la cache y los archivos locales al abrir el proyecto. Los ejecutables y respaldos locales estan excluidos del repositorio.
